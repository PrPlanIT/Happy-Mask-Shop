# Roundcube: SysEggplant

SysEggplant for the [Roundcube](https://roundcube.net/) webmail interface.

**Needs:** [Stylus](https://github.com/openstyles/stylus).

## Install

Open the `.user.css` file's raw view and let Stylus install it. It matches Roundcube pages by their `_task=` address
parameter, so it works on any host.
