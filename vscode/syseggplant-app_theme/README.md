# VS Code: SysEggplant

Workbench and syntax colours for [VS Code](https://code.visualstudio.com/), on top of the built-in "Default Light
Modern" theme.

## Install

Open the command palette, run **Preferences: Open User Settings (JSON)**, and merge these keys into it. The editor
font is set to NovaMono; install it or change `editor.fontFamily`.
