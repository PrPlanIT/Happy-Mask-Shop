# SearXNG: SysEggplant

Catppuccin's SearXNG userstyle with the Mocha flavour's base and mantle set to SysEggplant (`#301c35`, `#310937`).

**Needs:** [Stylus](https://github.com/openstyles/stylus).

## Install

Open the `.user.css` file's raw view and let Stylus install it. It matches the two public instances Catppuccin
lists; for your own instance, add its domain to the `@-moz-document` line. Use the Mocha dark flavour to see the
SysEggplant colours.
