# Vivaldi: SysEggplant

A [Vivaldi](https://vivaldi.com/) browser theme.

## Install

Vivaldi imports themes as a zip containing this file named `settings.json`:

```sh
cp vivaldi-syseggplant.app_theme.json settings.json && zip SysEggplant.zip settings.json
```

Then Settings → Themes → Import, and pick the zip.
