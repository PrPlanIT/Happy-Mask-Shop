# Facebook: SysEggplant

YAD's [Facebook Themer](https://uso.kkx.one/style/224452) userstyle with SysEggplant colours as its settings.
Covers facebook.com and messenger.com.

**Needs:** [Stylus](https://github.com/openstyles/stylus).

## Install

Open the `.user.css` file's raw view and let Stylus install it. The colours are already set.

To apply them to a copy of Facebook Themer you already have instead, open its settings (the gear beside it in the
Stylus menu) and enter:

| Setting | Colour |
| --- | --- |
| Accent Color | `#a94dc1` |
| Link Color | `#7bb7c8` |
| Icons Color | `#67b3a5` |
| Primary Text | `#408e6a` |
| Secondary Text | `#1d78cb` |
| Theme Color (background) | `#2f1c35` |
