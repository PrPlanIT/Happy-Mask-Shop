# Mealie: SysEggplant

SysEggplant colours for the [Mealie](https://mealie.io/) recipe manager, set through its theme environment variables.
Each comment in the file says what that colour paints.

## Install

Give the Mealie container these variables: as an `env_file` in Docker Compose, `--env-file` with `docker run`, or
`env` entries on a Kubernetes Deployment. Restart Mealie to apply them.
