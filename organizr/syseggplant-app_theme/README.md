# Organizr: SysEggplant

SysEggplant colours for [Organizr](https://organizr.app/), set through its own appearance settings.

## Install

Settings → Customize → Appearance → Colors & Themes: choose the **Organizr** theme, then enter each colour from the `.txt` file into the field of the same name and save.

| Setting | Value |
|---|---|
| Nav Bar Color | `#310937` |
| Nav Bar Text Color | `#24cc89` |
| Side Bar Color | `#310937` |
| Side Bar Text Color | `#24cc89` |
| Accent Color | `#2f1c35` |
| Accent Text Color | `#90a83b` |
| Button Color | `#24cc89` |
| Button Text Color | `#310937` |
