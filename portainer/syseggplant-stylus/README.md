# Portainer: SysEggplant

SysEggplant for the [Portainer](https://www.portainer.io/) web UI: sidebar, body and borders.

**Needs:** [Stylus](https://github.com/openstyles/stylus).

## Install

Open the `.user.css` file's raw view and let Stylus install it. It matches any site on port 9443, Portainer's
default HTTPS port; if yours differs, edit the `@-moz-document` line.
