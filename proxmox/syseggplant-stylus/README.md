# Proxmox VE: SysEggplant

Weilbyte's Discord-inspired dark theme for the Proxmox VE web UI, recoloured in SysEggplant.

**Needs:** [Stylus](https://github.com/openstyles/stylus).

## Install

Open the `.user.css` file's raw view and let Stylus install it. It matches port 8006 and hosts named `pve…` or
`proxmox…`.
