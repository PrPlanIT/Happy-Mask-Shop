# Homarr: SysEggplant

SysEggplant for a [Homarr](https://homarr.dev/) board, through the board's own appearance settings.

## Install

In the board's settings → Appearance:

| Setting | Value |
|---|---|
| Primary color | `#24cc89` |
| Secondary color | `#310937` |
| Item radius | Large |

Then paste the `.css` file into **Custom css**.
