# Home Assistant docs: SysEggplant

Jonas's "Home Assistant - Dark mode" userstyle for the [Home Assistant documentation](https://www.home-assistant.io/),
recoloured in SysEggplant. Also matches pages served on port 8123.

**Needs:** [Stylus](https://github.com/openstyles/stylus).

## Install

Open the `.user.css` file's raw view and let Stylus install it.
