# Leantime: SysEggplant userstyle

The browser-side version of the SysEggplant Leantime theme, from before it became a
[server theme](../syseggplant-app_theme/). Applies while Leantime's colour scheme is set to the company colours
(`#74ecbe` primary), and swaps Monofur in when you pick "Shantell Sans" as the font.

**Needs:** [Stylus](https://github.com/openstyles/stylus).

## Install

Open the `.user.css` file's raw view and let Stylus install it, then change `plan.optcp.com` in its
`@-moz-document` line to your Leantime's domain.
