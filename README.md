## Stylus

Most web themes are userstyles for [Stylus](https://github.com/openstyles/stylus), a browser extension for
[Firefox](https://addons.mozilla.org/en-US/firefox/addon/styl-us/),
[Chrome](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne) and
[Opera](https://addons.opera.com/extensions/details/stylus/). With Stylus installed, open a `.user.css` file's raw
view and Stylus offers to install it, then keeps it updated from this repository.
